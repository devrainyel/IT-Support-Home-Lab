# IT Support Home Lab

A practical IT support home lab focused on troubleshooting, networking, Windows administration, user support, and common L1 help desk scenarios.

## About

This repository documents my hands-on learning and troubleshooting practice while preparing for an entry-level IT Support / Help Desk role.

The goal of this lab is to develop practical skills in:

- Windows troubleshooting
- Hardware and software troubleshooting
- Network troubleshooting
- DNS and DHCP fundamentals
- User and account support
- Active Directory fundamentals
- Microsoft 365 troubleshooting
- Ticket documentation
- Incident prioritization and escalation
- Basic IT security

## Troubleshooting Methodology

For each scenario, I follow a structured troubleshooting process:

1. Understand the problem
2. Gather information
3. Check basic causes
4. Identify the probable cause
5. Apply a solution
6. Verify the solution
7. Document the resolution
8. Escalate when necessary

- Basic networking tools

- Microsoft 365
